# Foster Home Capacity Planner — Data Dictionary

This document describes local source files, normalization rules, and published read models.
All metrics use a fixed reporting date of `2026-07-01` and end-exclusive date intervals.

## Local source files

Never expose these through `public/` or upload raw child/placement records to Supabase.

| File | Description |
| --- | --- |
| `data/raw/provider_level_updated.csv` | Licensed foster-home providers |
| `data/raw/child_level.csv` | Child removal and discharge records |
| `data/raw/placement_level.csv` | Placement episodes |

### Provider source schema

| Column | Type | Description |
| --- | --- | --- |
| `id_provider` | integer | Unique provider identifier |
| `license_start_date` | date | License start date |
| `license_end_date` | date | License end date (end-exclusive active cutoff) |
| `county_provider` | string | Provider home county (normalize before joins) |
| `n_days_licensed` | integer | Total licensed days in source |
| `n_days_active` | integer | Union of foster-home placement active days |
| `min_age` | integer | Current minimum accepted child age |
| `max_age` | integer | Current maximum accepted child age |

### Child source schema

| Column | Type | Description |
| --- | --- | --- |
| `id_child` | integer | Unique child identifier (**privacy-restricted**) |
| `removal_date` | date | Date of removal (**privacy-restricted at child level**) |
| `discharge_date` | date | Discharge date; null means current child |
| `age_at_removal` | number | Age at removal; may be missing |
| `most_recent_age` | number | Most recent known age; may be missing |
| `removal_county` | string | County at removal (normalize before joins) |

### Placement source schema

| Column | Type | Description |
| --- | --- | --- |
| `id_child` | integer | Child identifier (**privacy-restricted**) |
| `placement_start_date` | date | Placement start |
| `placement_end_date` | date | Placement end |
| `resource_type_on_this_placement` | string | Placement type (`foster_home`, kin, nonfamily, etc.) |
| `placement_index` | integer | Sequential index per child; latest = max index |
| `removal_county` | string | Child removal county |
| `placement_county` | string | County where placement occurred |
| `id_provider` | integer | Provider ID for foster-home placements; null for kin |
| `placement_length` | integer | `placement_end_date - placement_start_date` |

## County normalization

Apply only this explicit map before joins and published metrics:

| Raw value | Normalized value |
| --- | --- |
| `Vermillion` | `Vermilion` |
| `De Witt` | `DeWitt` |

Log every normalization count during ETL. Do not use fuzzy matching.

## Age groups

| Group | Range | Notes |
| --- | --- | --- |
| `0–5` | 0–5 | Included in age-specific ratios |
| `6–12` | 6–12 | Included in age-specific ratios |
| `13–17` | 13–17 | Included in age-specific ratios |
| `Unknown` | missing age | Included in total demand; excluded from age-specific ratios |

## Processed local outputs

Generated by Python ETL into `data/processed/` (gitignored):

- Deidentified aggregate tables ready for Supabase upload
- No `id_child`, child-level removal/discharge dates, or child-level placement episodes

## Privacy contract

The browser must never receive:

- `id_child`
- Child-level `removal_date`
- Child-level `discharge_date`
- Child-level placement episodes

Provider activity periods are merged and contain no child IDs.

## Recruitment minimum-volume rules

A county is eligible for comparative recruitment priority only when:

- `current_foster_home_children >= 10`
- `active_providers >= 3`

## Retention outreach thresholds

Evaluate **High** before **Medium**.

### High outreach priority

- Inactive for at least 180 days
- Inactive, license expires within 90 days, and inactive for at least 60 days
- Engagement below 10% with at least 90 eligible licensed days in the recent window

### Medium outreach priority

- Inactive for at least 90 days
- Inactive and license expires within 180 days
- Engagement below 25% with at least 90 eligible licensed days
- Currently active and license expires within 60 days

### Low outreach priority

All other currently licensed providers.
